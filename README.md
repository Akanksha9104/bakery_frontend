# 🧁 Sweet Bliss Bakery Website

A modern and responsive bakery website built using HTML, CSS and JavaScript.  
This project showcases an attractive bakery interface with sections like home, about, menu, customer reviews, blogs and contact page.

---

## 🚀 Features

- 🎂 Beautiful bakery landing page
- 📱 Responsive website design
- 🍰 Cake and bakery product showcase
- 🛒 Add to cart buttons
- ⭐ Customer review section
- 📰 Blog section
- 📍 Contact form with map integration
- 🎨 Clean and modern UI design
